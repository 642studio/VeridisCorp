# Plantilla: ficha de marca

La ficha de marca es la fuente de datos que los agentes consultan antes de proponer contenido, campañas o investigaciones para una marca. Los documentos de knowledge de cada agente explican el oficio; la ficha dice cómo es esta marca en particular.

## Cómo usarla

1. Llena una ficha por marca o cliente. No mezcles dos marcas en el mismo documento.
2. Copia desde la línea `# Ficha de marca — <nombre>` hacia abajo. No pegues estas instrucciones.
3. En cada sección, borra las líneas de preguntas guía (las que empiezan con `>`) y escribe la respuesta debajo de "Respuesta".
4. Escribe cada respuesta de modo que se entienda sola, repitiendo el nombre de la marca: "El Mismo Sazón vende…", no "Vende…". El importador parte el documento por encabezados `##` y cada sección se guarda por separado.
5. Si un dato no es seguro, escríbelo con la marca POR CONFIRMAR. Si no se sabe, escribe "Sin dato" en vez de inventarlo. Las secciones vacías se pueden borrar.
6. Importa en MEMORIA → + IMPORTAR TEXTO, con el título `Ficha de marca — <nombre>`. Marca "Lo escribí yo: guardar como confirmado" solo si quien la llenó conoce la marca de primera mano (el dueño, el responsable de la cuenta). Si no, déjala sin confirmar para que se revise.
7. Para actualizarla, corrige el documento, cambia la fecha y vuelve a importarlo con el mismo título. Los precios, ofertas y metas cambian seguido: revísalos cada mes.
